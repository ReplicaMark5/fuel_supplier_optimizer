● 2. Objective Function (Minimize Total Cost)

  minimize: sum(
      customer_depot_volume[i] * (
          # Base costs (when no applicable tier is active)
          sum(
              base_cost[i,j,option] * option_bin[i,j] * (1 - sum(VT_bin[t] for t in applicable_tiers[i,j,option]))
              for all options, supplier_depots j
          ) +

          # Tier costs (when applicable tier is active)
          sum(
              tier_cost[i,j,t] * option_bin[i,j] * VT_bin[t]
              for all applicable tiers t, supplier_depots j, matching options
          )
      )
      for all customer_depots i
  )

● 3. Constraint Types

  A. Depot Assignment (Each customer depot gets exactly one supplier)

  # For each customer depot i:
  sum(
      C_cash_bin[i,j] + C_30_bin[i,j] + C_45_bin[i,j] + C_60_bin[i,j] +
      D_own_bin[i,j] + D_buy_bin[i,j] + D_rent_bin[i,j]
      for all available supplier_depots j
  ) = 1

  B. Option Availability (Only use available options)

  # For each customer depot i, supplier depot j, option combination:
  option_bin[i,j] = 0  if option not available for this combination

  C. Volume Tier Activation

  # For each tier configuration t:
  sum(
      customer_depot_volume[i] * option_bin[i,j]
      for all customer_depots i
      for all supplier_depots j in tier_participating_depots[t]
      for all options matching tier_modes[t]
  ) >= tier_threshold[t] * VT_bin[t]

  D. Mutual Tier Exclusion (At most one tier per supplier per mode)

  # For each supplier s, mode m combination:
  sum(VT_bin[t] for all tiers t where supplier[t] == s and mode[t] == m) <= 1
